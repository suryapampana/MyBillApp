💳 MyBillApp | Architect Edition
A high-fidelity, single-file financial tracking application built for mobile-first performance and persistent offline usage.
🚀 Live Demo
Access your personal bill map here: suryapampana.github.io/MyBillApp/.
✨ Key Features
• Fintech Dashboard: Real-time calculation of Monthly Total and Daily Burn rates to monitor financial health.
• Reduction Lab: An interactive "Simulator" mode with a pulsing Zap animation to test potential savings by "cutting" specific bills.
• Multi-View Architecture: Seamlessly switch between Board (Grid), List, and Calendar views to track payment cycles.
• Smart Calendar: Integrated date-picker and dot-mapping system to visualize payment density across the month.
• Custom Metadata: Add unlimited detail rows (e.g., Policy Number, Account ID) using a dynamic key-value system.
• Splash Experience: Professional animated splash screen for a native app-like feel on launch.
🛠️ Technical Stack
• Frontend: React 18 (via CDN).
• Logic: Babel Standalone (In-browser JSX transformation for mobile stability).
• Styling: Tailwind CSS (Utility-first responsive design).
• Data Persistence: HTML5 localStorage (Zero-server, 100% private data storage).
• Icons: Hardcoded SVG components for optimized offline loading.
